# Grille d'évaluation · Oral Workshop « Sauvez le lancement » (CESI)

Site d'évaluation des présentations orales du workshop **Analyse et gestion des risques — Sauvez le lancement** (mise en service d'une nouvelle ligne de production).

- Grille sur 20 : livrables /14 — identification (2,5), évaluation & criticité (2,5), traitement (2,5), contrôle & KRI (2), analyse QCD (1,5), décision de lancement (1,5), outils (1,5) ; oral /6
- 4 équipes pré-remplies, chrono 10 min par groupe
- Salle partagée : plusieurs membres du jury notent en parallèle, notes mutualisées en direct (moyenne, écart, commentaires)
- Export CSV et fiches PDF

Adapté de l'outil de Tom Frébault (grille--valuation-management). Partage temps réel via un lien secret `#salle=…` (relais ntfy.sh, messages conservés 12 h). Déployé sur GitHub Pages via GitHub Actions.
